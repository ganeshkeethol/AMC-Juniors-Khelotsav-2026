Q&A PAGE - GOOGLE SHEETS SETUP

1. Open the spreadsheet used for the High-Level Schedule and Notifications (the ID is HIGH_LEVEL_SCHEDULE_SHEET_ID in Code.gs).
2. Add a sheet/tab named exactly: Q&A
3. Add these headers in row 1: Question | Answer | Category | Active | Display Order
4. Add relevant event information questions and answers, one question per row. Do not add Kids Enrollment or registration-payment FAQs while the Kids Enrollment section is removed.
5. Use Active = Yes to show a question, or No to hide it. Display Order controls the order on the website. Category is used for category filter buttons.
6. In Apps Script, replace/update Code.gs with the updated Code.gs from this ZIP, save, then Deploy > Manage deployments > Edit > New version > Deploy. Keep the existing web app URL and access settings.
7. Upload qa.html and the updated navigation HTML files to the GitHub Pages repository.

The page reads Q&A rows through the existing Apps Script API using ?action=qna. No direct public publishing of the spreadsheet is required.
