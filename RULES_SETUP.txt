AMC JUNIORS KHELOTSAV 2026 — RULES & REGULATIONS SETUP

Google Sheet
Use the existing High-Level Schedule spreadsheet configured by HIGH_LEVEL_SCHEDULE_SHEET_ID. Create a new tab named exactly: Rules

Row 1 headers (exactly):
Audience | Category | Rule | Active | Display Order

Audience values: General, Participant, Volunteer.
Category is a short heading such as Attendance, Child Safety, Fair Play, Communication, Emergency Handling, or Venue Care.
Rule is the rule/guideline text to display.
Active should be Yes to show the row; use No to hide it.
Display Order is a number used to order the published rules.

Google Apps Script
The included Code.gs adds the action=rules endpoint. Paste/merge it into the Apps Script project used by config.js, then Deploy > Manage deployments > Edit > New version > Deploy. The website cannot fetch live rules until the new script version is deployed and the Rules tab exists.

Website
Upload rules.html and the updated index.html, event.html, qa.html, results.html, partners.html, highlights-2025.html, Code.gs as appropriate. Main navigation and the volunteer registration area link to the Rules page.
